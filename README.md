# Carlos | Portfólio

Portfólio pessoal do Carlos — estudante de Desenvolvimento de Software no Cotemig e desenvolvedor de IA na Ibituruna. Site de página única feito com HTML, CSS e JavaScript puros, sem frameworks e sem etapa de build.

**Acesse online:** https://carlosasevedox-gif.github.io/Portifolio/

## Seções

| Seção | O que tem |
| --- | --- |
| Início | Apresentação com efeito de digitação e uma "janela" de código SQL |
| 01. Sobre | Quem sou eu e números rápidos |
| 02. Habilidades | Cards com HTML/CSS, JavaScript, SQL, Python, IA e Git/GitHub |
| 03. Projetos | Destaque para o [Ficou Fera](https://ficoufera.com.br) e link para o GitHub |
| 04. Contato | Formulário com validação e máscaras de nome e telefone |

## Funcionalidades

- **Tema claro/escuro** com a escolha salva no navegador (`localStorage`)
- **Efeito de digitação** no título da página inicial
- **Animação de entrada** das seções conforme a rolagem
- **Máscaras no formulário**: o nome não aceita números e o telefone é formatado como `(31) 99999-9999`
- **Modal de confirmação** ao enviar o formulário (demonstração — a mensagem não é enviada para um servidor)
- **Layout responsivo** com ajustes para telas de até 900px e 600px

## Tecnologias

- HTML5
- CSS3 (variáveis, Flexbox, Grid e media queries)
- JavaScript puro
- Fontes [Space Grotesk](https://fonts.google.com/specimen/Space+Grotesk) e [JetBrains Mono](https://fonts.google.com/specimen/JetBrains+Mono) via Google Fonts

## Estrutura

```
Portifolio/

├── style.css    # estilos, temas e responsividade
├── script.js    # tema, digitação, animações e formulário

```

## Como rodar

Não precisa instalar nada. Baixe o repositório e abra o `index.html` no navegador:

```bash
git clone https://github.com/carlosasevedox-gif/Portifolio.git
```
